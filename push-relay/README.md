# Ретранслятор пуш-сповіщень

Маленький сервер, який дозволяє Гомону розбудити телефон, коли
застосунок закрито.

## Навіщо він потрібен

Поки Гомін відкритий (навіть у фоні), повідомлення приходять
напряму від співрозмовника — застосунок показує сповіщення сам,
жодного сервера. Коли ж застосунок закрито, прямого зʼєднання
немає: розбудити пристрій може тільки push-служба браузера
(Google FCM, Mozilla, Apple). Звертатися до неї дозволено лише з
підписом приватним ключем VAPID, а тримати такий ключ у браузері
не можна. Тому й потрібні ці 200 рядків.

## Що він бачить

Кому надіслати сигнал і від кого він прийшов. Більше нічого:
текст повідомлень, фото, голосові та дзвінки йдуть напряму між
пристроями і сюди не потрапляють.

## Запуск

```bash
cd push-relay
npm install
npm run keys     # один раз — створює vapid.json
npm start
```

Сервер слухає порт `8787` (змінюється через `PORT`).
Йому потрібна адреса `https://` — браузери не приймають підписку
через незахищене зʼєднання (виняток лише `http://localhost` для
перевірки). Найпростіше — Fly.io, Railway, Render, або власний
сервер за nginx з сертифікатом.

## Налаштування

| Змінна           | Значення                                                     |
|------------------|--------------------------------------------------------------|
| `PORT`           | порт, типово `8787`                                           |
| `VAPID_CONTACT`  | `mailto:` вашої пошти — цього вимагають push-служби           |
| `VAPID_PUBLIC`   | публічний ключ (замість файлу `vapid.json`)                   |
| `VAPID_PRIVATE`  | приватний ключ                                                |
| `ALLOW_ORIGIN`   | звідки приймати запити, через кому; типово `*`                |
| `VAPID_FILE`     | шлях до файлу з ключами                                       |

## Підключення в застосунку

**Налаштування → Сповіщення → «Пуш коли застосунок закритий»** →
вкажіть адресу сервера (наприклад `https://push.example.net`) →
**Підключити**.

Гомін сам візьме публічний ключ з `/key`, підпишеться на
push-службу і передасть свою адресу підписки друзям через уже
наявне зʼєднання. Далі, коли друг напише вам, а ваш застосунок
буде закритий, його Гомін постукає саме у **ваш** ретранслятор.

Один сервер спокійно обслуговує і кількох людей — вкажіть його
адресу в кожного, спільного облікового запису не потрібно.

## Ендпойнти

```
GET  /key      -> {"key":"<публічний ключ VAPID>"}
POST /push     <- {"subscription":{...},"payload":{"title","body","chatId","tag"}}
GET  /health   -> {"ok":true}
```

Обмеження: 60 сигналів за хвилину з IP-адреси, тіло запиту до 16 КБ,
поля сповіщення обрізаються до розумної довжини.
